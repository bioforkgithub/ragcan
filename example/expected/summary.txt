WHAT THIS IS, AND WHAT TO DO NEXT

This is a SCREEN, not a taxonomic conclusion. It is designed to be the first step:
to let you say "the screen indicated this, which is why we then did the following".

If a genome is flagged as a candidate novel taxon, or the bins disagree with the
current classification, the conventional next steps are:

  dry lab   ANI against type strains (< 95-96% supports a distinct species)
            dDDH (< 70% supports a distinct species)
            16S rRNA identity (< 98.7% supports a candidate new species)
            a phylogeny: align the ortholog groups written by this run with MAFFT,
            concatenate, and infer a tree with IQ-TREE

  wet lab   phenotypic and chemotaxonomic characterisation of the candidate:
            morphology, growth range, biochemistry, fatty acid and polar lipid
            profiles, respiratory quinones - as required to describe a novel taxon

Core gene sequences are written unaligned, per genome and per ortholog group, so
the phylogenetic step can start directly from this output.
